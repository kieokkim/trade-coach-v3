# TradeCoach — Agent Overview

> AI 기반 트레이딩 복기 코치
> ⚠️ 용어 주의: 현재 구현과 향후 계획이 명확히 구분됩니다. DECISION_LOG.md 참고.

## 한 줄 소개

트레이딩 거래내역을 분석하여 반복 실수를 진단하고,
ICT 이론 기반 맞춤 코칭으로 트레이더의 행동 패턴을 교정하는 AI 코치 에이전트

---

## 기존 분석 도구와의 차이

| 항목 | 기존 성과 분석기 | TradeCoach |
|------|--------------|-----------|
| 관심 대상 | 수익률 숫자 | 반복 실수 패턴 |
| 핵심 질문 | "얼마 벌었나?" | "왜 같은 실수를 반복하는가?" |
| 결과물 | 통계 리포트 | 내일 실행할 규칙 1개 |
| 메모리 | 없음 | 세션 간 약점 누적 추적 |
| 복기 | 없음 | 진입 시점 캔들 + ICT 분석 + A+ 채점 |

## 현재 구현된 기능 (v2.0~v2.2)

### 1. 거래내역 자동 분석 ✅
Bybit API로 거래내역을 자동 수집하고 4가지 KPI로 진단합니다.
API 키 없으면 샘플 데이터 3종(초보/중급/고수)으로 바로 체험 가능합니다.

| KPI | 의미 | 경고 기준 |
|-----|------|---------|
| 승률 | 수익 거래 비율 | 40% 미만 |
| 평균 수익률 | 투자금 대비 수익 % | 1% 미만 |
| 수익금 | 실현 손익 합계 | — |
| 손절 일관성 | 손절 규율 (낮을수록 좋음) | 2.0 초과 |

### 2. 거래 복기 뷰어 (Trade Context Viewer) ✅ v2.1 완료

- plotly 캔들차트 + 진입/청산 마커
- FVG / Order Block / 추세선 / 채널 감지 및 오버레이
- LLM 복기 코멘트

### 3. A+ 채점 시스템 ✅ v2.2 완료

ICT 이론 기반 5가지 기준 rule-based 자동 채점:

| 기준 | 내용 |
|------|------|
| 구조 진입 | 진입가가 FVG/OB 구간 내 |
| 반등 확인 | 직전 캔들이 구조 레벨에서 지지 |
| 추세 정렬 | 진입 방향과 추세선 일치 |
| 킬존 진입 | 런던/뉴욕 세션 시간대 |
| 손절 규율 | 당일 손절 3회 미만 |

### 4. 캔들 기반 진입 근거 자동 추론 ✅ v2.2 완료
캔들 데이터 + ICT 패턴을 LLM에 넘겨 "왜 이 시점에 진입했는가"를 자동 추론하고
개선 코칭을 제공합니다.

### 5. AI-as-Judge 코칭 검수 ✅ v2.2 완료
별도 LLM이 트레이딩 철학 5가지로 코칭 결과를 자동 검수합니다.
- 하루 3번 손절 시 거래 중단 언급 여부
- 최대 손실금액 고정 언급 여부
- Revenge Trading 경고 포함 여부 등

### 6. 메모리 기반 반복 실수 탐지 ✅
매 세션마다 약점을 누적 저장해서 반복 패턴을 추적합니다.

> "손절 불규칙이 3회 연속 감지됐습니다."

### 7. ICT 기반 약점 코칭 ✅
rule-based 약점 태깅으로 분류하고 개선 방법을 제시합니다.

> "내일의 규칙: 진입 전 손절가 먼저 설정"

## 예상 사용 시나리오

```
[시작 페이지]
Bybit API 키 입력 또는 샘플 데이터 선택
  ① 초보 트레이더 — 잦은 과매매, 손절 불규칙
  ② 중급 트레이더 — 킬존 무시, FVG 진입 시도
  ③ 고수 트레이더 — OB 기반 진입, 손절 규율 준수

[로딩 페이지]
거래내역 자동 수집 중...

[메인 대시보드]

📊 KPI 탭
  승률 40% / 평균 수익률 0.8% / 수익금 -12,000 USDT / 손절 일관성 2.4
  ⚠️ 반복 약점: 손절_불규칙 (3회 연속) · 킬존외_진입
  ★ 내일의 규칙: 진입 전 손절가 먼저 설정

📋 거래내역 탭
  거래 선택 → 복기 시작
  [캔들차트 — 정적 뷰어]
  ▲ 진입 / ▼ 청산 마커
  🟡 FVG 구간 / 🔵 Order Block / 📈 추세선 오버레이

  [A+ 채점 결과]
  ✅ 구조 진입 (FVG 구간 내)
  ✅ 킬존 진입 (뉴욕 세션)
  ❌ 추세 정렬 (역추세 진입)
  ❌ 손절 규율 (당일 4회 손절)
  → A+ 점수: 2/5

  복기 코멘트: "진입 시점에 FVG가 있었으나 OB 확인 없이 진입했습니다."

  [AI-as-Judge 검수 결과]
  ⚠️ 하루 3번 손절 초과 — 거래 중단 권고 미포함
  ✅ Revenge Trading 경고 포함
  ✅ 최대 손실금액 고정 언급

📚 셋업 태깅 탭
  익절 패턴 분류 / 손절 패턴 분류 / 개선 제안

[재방문]
신규 거래내역만 자동 추가
```

## 기술 구조

```
Bybit API (거래내역 + 캔들)
  ↓
LangGraph 파이프라인 (메인)
  ├── 데이터 수집 (new_data_check → bybit_fetch)
  ├── KPI 분석 (journal_analysis → weakness_detect)
  ├── 성과 요약 (performance_analysis)
  └── 코칭 생성 (backtest_coach → ai_judge)

거래 복기 플로우 (독립 실행)
  ├── 캔들 수집 (market/candles.py)
  ├── ICT 탐지 (ict/fvg_detector.py, ob_detector.py, mss.py)
  ├── A+ 채점 (entry_reason_node)
  └── 복기 코멘트 (replay_coach_node)

SQLite 메모리 → Streamlit 멀티페이지
```
